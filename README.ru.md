# Xiaomi Mi Router 3 — пользовательская прошивка OpenWrt с BIRD, WireGuard и частотой CPU 600 МГц

Пользовательская прошивка OpenWrt для **Xiaomi Mi Router 3 (MiWiFi R3)** на базе **OpenWrt 25.12.6**.

Сборка включает BIRD для маршрутизации BGP, поддержку WireGuard, диагностические инструменты и настройку частоты процессора с целевым значением 600 МГц.

## Возможности

- **OpenWrt 25.12.6**
- Платформа **MediaTek MT7620A**
- Частота процессора настроена на **600 МГц**
- **BIRD 3** для маршрутизации BGP
- Поддержка **WireGuard**
- Веб-интерфейс LuCI
- `iperf3` для тестирования пропускной способности сети
- `htop` для мониторинга процессов и использования ресурсов
- `mtr`, `traceroute` и утилиты для диагностики DNS
- IPv6 отключён; используется только IPv4
- Включена программная разгрузка обработки сетевых потоков (Flow Offloading) в межсетевом экране
- Пользовательские настройки сети и беспроводной сети по умолчанию
- Рабочий процесс GitHub Actions для автоматизированной сборки прошивки

## Конфигурация по умолчанию

### Сеть

- Имя роутера: `MIR3`
- Адрес LAN: `172.16.1.1/24`
- Диапазон DHCP в LAN: `172.16.1.128`–`172.16.1.191`
- Локальный домен DNS: `mir3`
- Интерфейс WAN: получение IP-адреса и сетевых параметров по DHCP от провайдера.

### Беспроводная сеть

- Имя сети (SSID) по умолчанию: `Mir3-2.4GHz/Mir3-5GHz`
- Пароль Wi-Fi по умолчанию: `0123456789`
- Для увеличения допустимой мощности используется страны `PA`, мощность передачи `21` для `radio0` (5 ГГц) и `36` для `radio1` (2,4 ГГц)

### Доступ

- Пароль пользователя `root` по умолчанию: `0123456789`
- Порт SSH: `22`
- Доступ по SSH разрешён из LAN, WAN и зоны межсетевого экрана WireGuard.

**Примечание по безопасности:** это учётные данные по умолчанию, предусмотренные данной пользовательской сборкой. Перед предоставлением доступа к роутеру из недоверенных сетей оцените связанные с этим риски безопасности.

## BIRD и BGP

BIRD включён в сборку с шаблонной конфигурацией. Локальный номер AS и BGP-соседи заранее не настроены.

Перед использованием маршрутов BGP настройте локальный номер AS, идентификатор маршрутизатора (Router ID), адреса соседей, удалённые номера AS и политики маршрутизации для своей сети.

## WireGuard

В сборку включены инструменты WireGuard и поддержка протокола в LuCI.

При сборке инициализируется интерфейс `wg0`, однако для работы туннеля необходимо указать собственный приватный ключ WireGuard, публичный ключ узла-пира, адрес конечной точки (endpoint), разрешённые диапазоны IP-адресов, а также необходимые настройки маршрутизации и межсетевого экрана.

Не публикуйте в репозитории приватные ключи и другие секретные данные.

- `config/.config` — конфигурация сборки OpenWrt.
- `patches/` — патчи, применяемые к исходному дереву OpenWrt.
- `overlay/` — пользовательские файлы, копируемые в исходное дерево OpenWrt во время сборки.
- `OPENWRT_COMMIT` — точная ревизия исходного кода OpenWrt, используемая при сборке.
- `.github/workflows/build.yml` — рабочий процесс GitHub Actions для сборки прошивки.
- `sha256sums.txt` — файл контрольных сумм, если он создаётся или поддерживается для публикуемых артефактов прошивки.

## Сборка прошивки

В репозитории используется GitHub Actions для автоматизации сборки.

1. Отправьте репозиторий на GitHub.
2. Откройте репозиторий на GitHub.
3. Перейдите на вкладку **Actions**.
4. Откройте рабочий процесс сборки прошивки.
5. Запустите рабочий процесс вручную, если включён `workflow_dispatch`, либо отправьте изменение в один из путей, отслеживаемых рабочим процессом.
6. Дождитесь завершения рабочего процесса.
7. Откройте завершённый запуск рабочего процесса и скачайте артефакты прошивки, если рабочий процесс их публикует.

Рабочий процесс получает зафиксированную ревизию исходного кода OpenWrt, применяет патч и дополнительные файлы проекта, устанавливает пакетные фиды, загружает конфигурацию сборки и компилирует прошивку.

Для локальной сборки следуйте той же последовательности, которая используется в `.github/workflows/build.yml`. Не предполагайте, что стандартная процедура сборки OpenWrt подходит для этого репозитория без выполнения специфичных для проекта шагов применения патчей и дополнительных файлов.

## Установка прошивки

Перед прошивкой убедитесь, что образ предназначен именно для **Xiaomi Mi Router 3 (MiWiFi R3)**, и используйте способ установки, поддерживаемый текущей прошивкой и имеющейся системой восстановления.

- Сохраните копию текущей конфигурации, если она вам понадобится.
- Если для загруженного образа предоставлена контрольная сумма, проверьте её.
- Не отключайте питание во время прошивки.
- Перед обновлением подготовьте способ восстановления роутера.

Прошивка неподходящего образа или прерывание процесса могут привести к невозможности загрузки роутера.

## Локальная сборка Xiaomi Mi Router 3 в WSL Ubuntu

### 1. Установка зависимостей

```bash
sudo apt-get update
sudo apt-get install -y build-essential clang flex bison g++ gawk gcc-multilib g++-multilib gettext git libncurses-dev libssl-dev python3-setuptools rsync swig unzip zlib1g-dev file wget libelf-dev ecj fastjar java-propose-classpath python3 python3-dev python3-pyelftools python3-venv qemu-utils squashfs-tools
```

### 2. Клонирование репозитория проекта

```bash
cd ~
git clone https://github.com/LexPnz/xiaomi-mi-router-3-openwrt-bird-wg.git github-lexpnz-xiaomi-mi-router-3-openwrt-bird-wg
cd ~/github-lexpnz-xiaomi-mi-router-3-openwrt-bird-wg
```

### 3. Загрузка закреплённой версии OpenWrt

Команды выполняются из корня репозитория проекта. Исходники OpenWrt будут находиться в подкаталоге `openwrt`.

```bash
cd ~/github-lexpnz-xiaomi-mi-router-3-openwrt-bird-wg || exit 1

git init openwrt
git -C openwrt remote add origin https://github.com/openwrt/openwrt.git

OPENWRT_COMMIT="$(cat OPENWRT_COMMIT)"
git -C openwrt fetch --depth 1 origin "$OPENWRT_COMMIT"
git -C openwrt checkout --detach FETCH_HEAD

test "$(git -C openwrt rev-parse HEAD)" = "$OPENWRT_COMMIT" \
  && echo "OK: OpenWrt commit совпадает"
```

### 4. Применение патча и overlay

```bash
cd ~/github-lexpnz-xiaomi-mi-router-3-openwrt-bird-wg || exit 1

git -C openwrt apply --check "$PWD/patches/0001-mir3-customizations.patch"
git -C openwrt apply "$PWD/patches/0001-mir3-customizations.patch"
cp -a overlay/. openwrt/
```

### 5. Подготовка feeds и конфигурации

```bash
cd ~/github-lexpnz-xiaomi-mi-router-3-openwrt-bird-wg/openwrt || exit 1

./scripts/feeds update -a
./scripts/feeds install -a
cp ../config/.config .config
make defconfig
```

### 6. Загрузка исходников и сборка

Перед сборкой сбросьте `PATH`, чтобы Windows-программы, включая компоненты NVIDIA, не мешали работе Linux-инструментов.

```bash
cd ~/github-lexpnz-xiaomi-mi-router-3-openwrt-bird-wg/openwrt || exit 1

export PATH="/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"

make download -j"$(nproc)"

set -o pipefail
make -j"$(nproc)" V=s 2>&1 | tee ~/mir3-local-build.log
```

`pipefail` позволяет обнаружить ошибку `make`, даже если вывод передаётся через `tee`.

### 7. Расположение готовой прошивки

Готовые образы Xiaomi Mi Router 3 находятся в каталоге:

`openwrt/bin/targets/ramips/mt7620/`

Проверить sysupgrade-образ и контрольные суммы:

```bash
find ~/github-lexpnz-xiaomi-mi-router-3-openwrt-bird-wg/openwrt/bin/targets/ramips/mt7620 \
  -maxdepth 1 -type f \
  \( -name '*xiaomi_miwifi-r3*squashfs-sysupgrade.bin' -o -name 'sha256sums' \) \
  -printf '%TY-%Tm-%Td %TH:%TM  %s bytes  %f\n'
```

Лог сборки: `~/mir3-local-build.log`.

**Примечание:** этот порядок предназначен для первичной сборки в чистом каталоге. При повторной сборке не нужно повторно инициализировать Git, применять уже применённый патч или копировать overlay без проверки состояния исходников.
