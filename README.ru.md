# Xiaomi Mi Router 3 — OpenWrt 25.12.6 с BIRD 3, WireGuard и частотой CPU 600 МГц

Кастомная сборка OpenWrt для **Xiaomi Mi Router 3 (R3)** на платформе MediaTek MT7620A. Включает BIRD 3 для BGP, поддержку WireGuard, диагностические инструменты и настройки устройства.

## Характеристики сборки

| Параметр | Значение |
|---|---|
| Устройство | Xiaomi Mi Router 3 |
| Модель платы | `xiaomi,miwifi-r3` |
| SoC | MediaTek MT7620A |
| Целевая платформа | `ramips/mt7620` |
| Архитектура пакетов | `mipsel_24kc` |
| Базовая система | OpenWrt 25.12.6 |
| Частота CPU | 600 МГц |
| IPv6 | Отключён |
| BIRD | BIRD 3 |
| WireGuard | Поддержка ядра и `wireguard-tools` |
| LuCI | Веб-интерфейс и поддержка WireGuard |

Частота CPU задаётся конфигурацией сборки. Фактическую частоту и стабильность работы следует проверять на самом устройстве.

## Что включено

- **BIRD 3** — маршрутизация BGP.
- **WireGuard** — поддержка VPN-интерфейсов.
- **LuCI WireGuard protocol** — настройка WireGuard через веб-интерфейс.
- **iperf3** — проверка пропускной способности сети.
- **htop** — мониторинг процессов и нагрузки.
- **mtr**, `traceroute` и DNS-диагностические инструменты.
- Дополнительные настройки для Xiaomi Mi Router 3.
- Настройки Wi-Fi и первоначальной конфигурации устройства.

BIRD и WireGuard требуют настройки под конкретную сеть. Параметры AS, соседей BGP, адресацию и VPN-подключение необходимо настроить отдельно.

## Сеть и доступ

Основные параметры текущей конфигурации:

| Параметр | Значение |
|---|---|
| LAN | `172.16.1.1/24` |
| WAN | `172.16.5.251/24` |
| WAN-интерфейс | `eth0.2` |
| WireGuard-интерфейс | `wg0` |
| SSH | TCP-порт `22` |

Интерфейс `wg0` включён в конфигурацию, но наличие интерфейса само по себе не означает, что VPN-туннель уже подключён: параметры peer и ключи необходимо настроить отдельно.

## Учётные данные по умолчанию

- **Пароль root:** `0123456789`
- **Пароль Wi-Fi:** `0123456789`

SSH доступен из зон LAN, WAN и WireGuard согласно настройкам firewall этой сборки.

После первого входа рекомендуется сменить пароль root и пароль Wi-Fi. Если SSH-доступ со стороны WAN не нужен, ограничьте его правилами firewall.

## Самостоятельная сборка

### Требования

- Linux или WSL2 с Ubuntu.
- Git и инструменты сборки, необходимые OpenWrt.
- Достаточно свободного места на диске и оперативной памяти.

### 1. Получение исходников проекта

```sh
git clone https://github.com/LexPnz/xiaomi-mi-router-3-openwrt-bird-wg.git
cd xiaomi-mi-router-3-openwrt-bird-wg
```

### 2. Получение закреплённой ревизии OpenWrt

```sh
git clone https://github.com/openwrt/openwrt.git openwrt
cd openwrt

git checkout "$(cat ../OPENWRT_COMMIT)"
```

Проверьте, что рабочая ревизия совпадает с указанной в `OPENWRT_COMMIT`:

```sh
git rev-parse HEAD
cat ../OPENWRT_COMMIT
```

Обе команды должны вывести одинаковый commit hash.

### 3. Применение патча и overlay

```sh
git apply --check ../patches/0001-mir3-customizations.patch
git apply ../patches/0001-mir3-customizations.patch

cp -a ../overlay/. .
```

Если проверка `git apply --check` завершилась ошибкой, остановитесь и проверьте совместимость патча с выбранной ревизией OpenWrt.

Дополнительные патчи ядра, если они предусмотрены текущей версией репозитория, должны находиться в каталогах, ожидаемых системой сборки. Перед запуском убедитесь, что они присутствуют и применяются автоматически либо предусмотренным workflow способом.

### 4. Настройка feeds и конфигурации

```sh
./scripts/feeds update -a
./scripts/feeds install -a

cp ../config/.config .config
make defconfig
```

После `make defconfig` проверьте основные параметры:

```sh
grep -E '^CONFIG_PACKAGE_(bird3|htop|iperf3|wireguard-tools|luci-proto-wireguard)=y$' .config
grep '^CONFIG_IPV6=' .config
```

Убедитесь, что нужные пакеты включены, а IPv6 остаётся отключённым.

### 5. Сборка

```sh
make download
make -j"$(nproc)"
```

Готовые образы обычно располагаются в каталоге:

```text
bin/targets/ramips/mt7620/
```

Конкретное имя файла зависит от настроек сборки.

**Важно:** успешная компиляция не гарантирует работоспособность всех функций на реальном устройстве. Перед установкой проверьте состав образа, контрольную сумму и возможность восстановления роутера.

## Установка прошивки

Перед обновлением:

1. Убедитесь, что образ предназначен именно для Xiaomi Mi Router 3 (`xiaomi,miwifi-r3`).
2. Сохраните необходимые настройки и конфигурационные файлы.
3. Проверьте SHA-256 скачанного файла.
4. Используйте подходящий для текущей системы способ обновления.
5. Не отключайте питание во время записи прошивки.

Неподходящий образ или прерывание записи могут привести к неработоспособности устройства.

## Проверка SHA-256

Файл `sha256sums.txt` содержит контрольные суммы перечисленных в нём файлов. Сравнивайте хеш только с записью, соответствующей точному имени скачанного образа.

В Linux выполните:

```sh
sha256sum ИМЯ_ФАЙЛА
```

Полученное значение должно совпасть с соответствующей записью в `sha256sums.txt`. Если нужного файла в списке нет, не используйте хеш другого образа.

## Ограничения и статус проверки

- Проект предназначен для Xiaomi Mi Router 3 с платформой MT7620A.

- Совместимость с другими моделями и ревизиями OpenWrt не гарантируется.
- Если сборка из чистого дерева ещё не прошла независимую проверку, её следует считать непроверенной до завершения такого теста.
