# BIRD 3 + AmneziaWG 3.1 — Xiaomi Mi Router R3

## РУССКИЙ

В прошивке предустановлены BIRD 3 и AmneziaWG 3.1.

### 1. Настройка AmneziaWG

Для работы интерфейса `awg0` необходимо использовать конфигурацию, совместимую с AmneziaWG 3.1 и настройками VPN-сервера. Например, конфигурацию можно подготовить на сайте https://awgconfig.com/.

Импортируйте полученную конфигурацию через LuCI или настройте интерфейс вручную в `/etc/config/network`.

Перед настройкой выборочной маршрутизации через BGP убедитесь, что интерфейс `awg0` настроен и VPN-туннель успешно установлен.

### 2. Настройка BGP через ANTIFILTER.NETWORK

В конфигурацию сети добавлен статический маршрут до BGP-сервера ANTIFILTER.NETWORK (`45.154.73.71`) через интерфейс `awg0`. Он предназначен для обеспечения доступности BGP-сервера через VPN, поскольку его адрес может быть недоступен напрямую из некоторых сетей.

Для настройки BGP отредактируйте файл `/etc/bird.conf`. VPN-туннель и маршрут до BGP-сервера должны быть настроены и работать до установления BGP-сессии.

Рекомендуется указать уникальный `router id` в соответствии с требованиями конфигурации BIRD.

После успешного установления BGP-сессии BIRD сможет получать маршруты от настроенного BGP-соседа. Фактическая маршрутизация трафика зависит от принятых маршрутов, политик BIRD и таблиц маршрутизации операционной системы.

Трафик, для которого не найден более специфичный маршрут, обычно направляется по маршруту по умолчанию, если другие правила маршрутизации не задают иное поведение.

Информация и материалы проекта ANTIFILTER.NETWORK: https://antifilter.download/

### 3. Проверка маршрутизации

Чтобы проверить, через какой интерфейс ядро Linux направляет трафик к определённому IP-адресу, выполните:

```sh
ip route get 1.1.1.1
```

Если для этого адреса выбран маршрут через VPN, в выводе должен быть указан интерфейс `awg0`. Если указан другой интерфейс, например `wan`, ядро направляет трафик через него.

Адрес `1.1.1.1` приведён только в качестве примера. Результат зависит от текущей таблицы маршрутизации и маршрутов, установленных системой.

Чтобы проверить маршруты, полученные через BGP, используйте:

```sh
birdc show protocols
birdc show route
```

Первая команда показывает состояние протоколов BIRD, а вторая — маршруты в таблице BIRD. Для проверки конкретного маршрута можно использовать `birdc show route for 1.1.1.1`.
